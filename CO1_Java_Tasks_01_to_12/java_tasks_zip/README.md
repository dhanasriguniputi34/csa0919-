# CO1 Java Assignment – Task-wise Programs

This ZIP contains one beginner-friendly Java program for each of Tasks 1–12. Each task is kept in its own folder.

## How to run
1. Install a JDK (Java 8 or later).
2. Open a terminal in the required task folder.
3. Compile: `javac TaskXX.java` (replace XX with the task number).
4. Run: `java TaskXX`.

Example for Task 01:
```bash
cd Task01
javac Task01.java
java Task01
```

Note: These are separate demonstration programs based on the task-wise code previously provided. The written analysis, pseudocode, UML diagrams, complexity discussion, and testing evidence requested in the assignment PDF are not included. Review and understand each program before submission.
